# Cloud Computing Concepts Reflection

Cloud computing has become an important part of my daily life because many of the applications I use depend on cloud services. Although I often use these applications for communication, file storage, and entertainment, I did not realize how much cloud computing supports them until I studied this course. Learning about cloud service models and deployment models helped me understand how these technologies make online services more accessible, reliable, and efficient.

## 1. Cloud Services I Use

Three cloud services that I use regularly are **Google Drive**, **Facebook Messenger**, and **Canva**.

## 2. Identify the Models

Google Drive is an example of **Software as a Service (SaaS)** because it allows users to store, organize, and share files through a web browser without installing or managing any servers. It uses the **Public Cloud** deployment model since it is available to anyone with a Google account.

Facebook Messenger is also classified as **Software as a Service (SaaS)** because Meta provides the messaging platform while users simply access it through the internet. It also uses the **Public Cloud** because millions of people around the world can use the same service.

Canva is another **Software as a Service (SaaS)** application because it offers online graphic design tools that users can access without installing professional software. Like the others, it follows the **Public Cloud** deployment model since it is available to the general public through the internet.

## 3. Git & GitHub for Cloud Projects

Version control is essential when working with cloud infrastructure because projects often involve multiple developers making changes at the same time. Without version control, files could be accidentally overwritten or important changes could be lost. Git helps record every modification made to a project, making it easier to review changes or restore previous versions if needed. GitHub enhances collaboration by allowing team members to work on separate branches, review code before merging, and keep a complete history of the project. These features reduce errors, improve teamwork, and make cloud-based projects more organized and easier to manage.
